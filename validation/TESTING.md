# 测试记录

## 环境与范围

- 开发目标：国服正式服 12.1.0；本机客户端安装信息为 12.1.0.69933。
- 本地 Lua 语法和行为测试使用 Lua 5.1（Python Lupa 2.6 的 lua51 运行时）。
- 插件完全独立，仅使用暴雪 API 和界面模板，无第三方运行库。
- 不读取或改写其他插件的 SavedVariables，不注册全局界面钩子，不自动分配或覆盖按键，不修改图形设置、分辨率或 UIParent 缩放。
- 0.2.0 增加用户触发的组队聊天通报和默认关闭的插件焦点通信；没有外部通信服务，也不把收到的焦点或声明存入 SavedVariables。
- 0.3.0 新增多行声明模板、背景不透明度、细分通报拒发提示和 `/ptw status` 本地公开诊断。
- 0.3.1 移除主动普通聊天目标通报及其按钮、成员行点击、命令、快捷键和专用诊断；保留自定义声明接收、背景不透明度与默认关闭的公开焦点共享。
- 0.4.0 新增 `%name` 公开聊天名称捕获、名称声明显示与“加入名称格式”草稿按钮；没有恢复普通聊天主动发送或新增手动标记映射。
- 0.4.2 删除插件间焦点同步的协议、注册、收发、缓存与开关；保留聊天通报接收及本机公开焦点只读显示，新增小地图按钮与游戏设置分类入口。
- 安装文件更新不等于实机通过。模拟测试不能证明真实 secret、taint、服务器送达或限流行为。

## API 依据

- 目标名称和标记的本地显示使用客户端允许的 UI 接口；秘密值不参与拼接、匹配或通信。共享身份只使用确认公开的当前组员全名进行归一化校验。
- 通信锁定不等于普通战斗；活动大秘境可能整段受限。0.4.2 已移除插件间通信，仅识别游戏允许读取的公开聊天。外部 HTTP 服务不会把秘密值变为公开焦点，项目不提供这种绕过方式。
- 版本锁定的 API 来源、枚举、限制事件和外部服务结论见 [API-NOTES.md](../docs/API-NOTES.md)。mock 不能代替客户端的受限值与显示行为验证。

## 游戏内验收步骤

1. 启用 PartyTargetWatch 后登录游戏；若新增插件未被识别，退出客户端后重新打开。
2. 单人时应直接看到“队友目标”窗口；选中与清空目标，检查自己的那一行。
3. 组队后请另一名队员切换目标、清空目标，确认对应行随游戏 API 提供的数据变化；检查队员离线、入队、退队。
4. 在战斗中检查名称是否仍能显示，并查看是否产生 PartyTargetWatch 的 Lua 错误。
5. 点击“设置”，调整整体大小和 X/Y 偏移；测试拖动标题、锁定、隐藏、显示、窗口居中。
6. 点击预览应明显标注“示例预览”；结束预览后必须恢复真实单位数据。
7. 执行 `/reload`，检查位置、大小、锁定和隐藏设置保存，示例预览默认结束。
8. 如用于团队，检查 21–40 名成员的双列布局。
9. 检查目标标记设置与取消；逐项切换场景筛选，确认休息区与副本分类、隐藏状态和预览行为。
10. 确认没有目标通报按钮或快捷键项，点击成员行不发送消息；旧版升级后的安装目录应没有 `Bindings.xml`。
11. 确认没有插件间同步开关；升级清理旧 `shareFocus` 字段后，显示列、聊天接收、格式、位置与背景设置仍保留。本机公开焦点只读显示，其他客户端不通过插件消息交换焦点。
12. 启用通报接收，验证两个标记模板接受的中文标记名、`1`–`8`、`{rt1}`–`{rt8}` 与“取消打断”；确认黄色“约定”、300 秒过期、换场景清理以及本人公开焦点优先。关闭接收后不能继续采用聊天缓存。
13. 从 `/ptw settings` 的“接收格式…”和 `/ptw formats` 打开编辑器。测试 20 条模板、长行换行与光标滚动、中文输入、竖线及 `%mark`/`%name`/`%text` 的原文保留；有效模板必须按顺序匹配整句，`%text` 不接受空字符串，同模板匹配不同名称或标记时拒绝。
